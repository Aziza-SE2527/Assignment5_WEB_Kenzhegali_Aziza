**Student:** Aziza

## Description
This project is the solution for Assignment #5. It demonstrates fundamental JavaScript concepts, including working with the Document Object Model (DOM), handling user events, and building basic application logic. The user interface is styled using a custom navy-blue, white, and pastel-pink color palette.

## Features & Tasks Completed
* **Part 1 (Introduction):** Basic variables, arithmetic operations, and console outputs.
* **Part 2 (DOM Manipulation):** Dynamically changing text content, altering CSS styles (colors and font sizes), and dynamically creating or removing list elements.
* **Part 3 (Events):** Mouseover/mouseout effects, real-time keyboard event tracking, and a functional four-operation calculator.
* **Part 4 (Interactive To-Do List):** A mini-project where users can add tasks (with a title and description), mark them as completed (strike-through effect), and delete them. Tasks are temporarily stored and managed within a JavaScript array.

## Navigation
The project includes a sticky navigation bar that links directly to the different parts of the assignment on the page for easy access.

## How to Run Locally
1. Clone this repository or download the source code files.
2. Open the `index.html` file in any modern web browser.
3. Use the navigation bar to jump between different tasks.
4. For Task 0 and Task 1 (Part 1), right-click on the page, select **Inspect**, and go to the **Console** tab to view the script outputs.
